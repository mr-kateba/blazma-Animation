Microsoft Visual C++ runtime (app-local copy in tools\kimodo)

tools\kimodo\kimodo-runner.exe and its GGML libraries are built with Microsoft Visual C++ and need the Visual C++ runtime.
Blazma Animation ships an unmodified, Microsoft-signed copy of these runtime files next to them (app-local deployment), so
AI motion generation works without administrator rights and without installing vc_redist.x64.exe:

  msvcp140.dll, msvcp140_1.dll, msvcp140_2.dll, msvcp140_atomic_wait.dll, msvcp140_codecvt_ids.dll,
  vcruntime140.dll, vcruntime140_1.dll, vcruntime140_threads.dll (when present), concrt140.dll   (Microsoft.VC14x.CRT)
  vcomp140.dll                                                                                    (Microsoft.VC14x.OpenMP)

They are copied at release time from the "VC\Redist\MSVC\<version>\x64" folder of Microsoft Visual Studio 2022 (the
folder Microsoft designates for redistribution), checked to carry a valid Microsoft Authenticode signature and a version
of at least 14.40, and listed with their SHA-256 in tools\kimodo\SHA256SUMS-vcruntime.txt (the exact version is in
tools\kimodo\VCRUNTIME_VERSION.txt).

updates the system copy through Windows Update; the app-local copy is updated with each Blazma Animation release.
