NVIDIA CUDA runtime libraries (only in the optional "GPU acceleration (CUDA)" download)

The optional download blazma-cuda-backend-<version>-win-x64.zip (installed only when the user presses
"Download GPU acceleration" in Settings -> AI, into %LOCALAPPDATA%\BlazmaAnimation\runtime\cuda or
userdata\runtime\cuda in portable mode) contains these files from the NVIDIA CUDA Toolkit 12.4 for Windows x64, unmodified:
  cudart64_12.dll, cublas64_12.dll, cublasLt64_12.dll
They are redistributed under the NVIDIA CUDA Toolkit End User License Agreement, Attachment A
("Redistributable Software"): https://docs.nvidia.com/cuda/eula/index.html
Copyright (c) NVIDIA Corporation. All rights reserved.

They are used only by ggml-cuda.dll (GGML's CUDA backend, MIT, see GGML_LICENSE.txt), which kimodo-runner
loads at run time when an NVIDIA graphics card and driver are present. They are not part of Blazma's
source code, are not covered by Blazma's licence, and may only be redistributed as part of this application
under NVIDIA's terms. Without an NVIDIA driver they are not used. "Remove GPU acceleration" in Settings -> AI
(or uninstalling Blazma) deletes them; Vulkan and the CPU keep working.
