# Khronos sample models

Rigged glTF sample assets from the [Khronos glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
repository, used by the skeleton-import tests (`tests/Blazma.Tests/Rigging/Import/KhronosSampleTests.cs`).
The files are unmodified copies of the `glTF-Binary` variants.
