# المخاطر والأسئلة المفتوحة

| # | الخطر | الأثر | المعالجة |
|---|---|---|---|
| R1 | بيئة العمل السحابية الحالية لا تحتوي على Godot ولا .NET SDK | لا يمكن بناء التطبيق أو اختباره هنا حاليًا | إعداد سكربت تثبيت للبيئة (SessionStart hook أو setup script) في بداية المرحلة 1، والتحقق من الوصول الشبكي لتنزيلهما |
| R2 | لقطات الشاشة الحقيقية لواجهة Godot داخل حاوية بلا GPU | قد لا يعمل Vulkan، ووضع `--headless` لا يلتقط صورًا (Renderer وهمي) | Xvfb + واجهة Compatibility، أو lavapipe لـVulkan، ويُوثَّق إذا تعذّر |
| R3 | تراخيص نماذج Kimodo | منع التوزيع التجاري | استبعاد SMPL-X نهائيًا. SOMA/G1 تحت NVIDIA Open Model License تحتاج مراجعة نصية كاملة. مكونات Llama 3 تخضع لـLlama 3 Community License (شروط الإسناد والتسمية) وتحتاج مراجعة منفصلة. الأوزان لا تُوزَّع مع البرنامج، والمستخدم يجلبها بنفسه |
| R11 | انتهاء دعم .NET 8 في 10 نوفمبر 2026، وGodot 4.7.2 يستهدف net8.0 | الشحن على نسخة غير مدعومة | المكتبات net8.0+net10.0، وCLI/MCP على net10، والتحقق من إمكانية نقل مشروع Godot إلى net10 |
| R4 | متطلبات ذاكرة Kimodo (العرض التجريبي ~10 GiB VRAM) | لن يعمل على الأجهزة المتوسطة كما هو | التكميم q4_k، حد ذاكرة مقيّد، CPU fallback، وقياس فعلي قبل أي ادعاء. الميزة اختيارية |
| R5 | Kimodo يتنبأ بـ30 مفصلًا في SOMA، والتوسيع إلى 77 غير منفّذ | الأصابع والوجه غير مولّدة | توليد الجسم فقط ويُترك الباقي للتحرير اليدوي، مع توضيح ذلك في الواجهة |
| R6 | FBX مغلق المواصفات | استيراد/تصدير غير موثوق | glTF أولًا. FBX عبر مكتبة خارجية لاحقًا بعد اختبار ملفات حقيقية |
| R7 | دعم RTL في عناصر Godot المخصصة (Timeline، Graph) | قص أو انعكاس خاطئ | Viewport والـTimeline والـGraph لا تنعكس (الزمن من اليسار لليمين دائمًا)، واللوحات والنصوص فقط تنعكس. اختبارات بصرية للعربية |
| R8 | خط عربي مرخّص | مشاكل توزيع | IBM Plex Sans Arabic أو Noto Sans Arabic (كلاهما SIL OFL 1.1)، يُضمَّن مع ملف الترخيص |
| R9 | تزامن تعديلات الوكيل مع تعديلات المستخدم في التطبيق المفتوح | تضارب | كل الأوامر تمر بطابور واحد على خيط الأوامر، وقفل ملف للوضع Headless |
| R10 | نطاق المشروع ضخم جدًا | عدم الإنجاز | التزام صارم بالمراحل، والقتال وKimodo بعد اكتمال المحرر الأساسي |

## أسئلة تحتاج قرارك

1. **الترخيص:** ما ترخيص Blazma Animation نفسه؟ (مغلق تجاري؟ مفتوح؟) لم أُنشئ ملف `LICENSE` حتى تقرر.
2. **اتجاه الواجهة:** أي النماذج الثلاثة (A/B/C) أو مزيج منها؟ انظر MOCKUPS.md.
3. **لون الهوية:** هل نعتمد Muted Burnt Amber مؤقتًا؟
4. **الخط العربي:** IBM Plex Sans Arabic أم Noto Sans Arabic؟
5. **البيئة:** هل نجهّز تثبيت Godot 4.7.2 و.NET تلقائيًا في هذه البيئة السحابية، أم سيتم البناء والاختبار على جهازك؟
