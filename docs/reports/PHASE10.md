# تقرير المرحلة 10 — الجاهزية للإنتاج

التاريخ: 2026-11-06 · الحالة: **مكتملة**

## ما تم
- **بناء الإصدار محليًا بأمر واحد:** `scripts/build-release.sh <version> --from-git` — اختبارات النواة، تصدير Godot لـ Windows وLinux، أدوات الوكلاء (blazma-mcp وblazma-anim) كملف واحد مستقل، ثم الحزم.
- **الحزم:**
  - مثبّت Windows (NSIS): لكل مستخدم بلا صلاحيات مدير، اختصار في قائمة ابدأ (وسطح المكتب اختياريًا)، إزالة، وربط ملفات `.blazanim`.
  - نسخة Windows محمولة (zip) فيها `portable.txt`: الإعدادات والاستعادة والسجل تُحفظ في `userdata` بجانب البرنامج.
  - Linux: tar.gz وAppImage.
  - `SHA256SUMS.txt` وملاحظات الإصدار.
- **اختبارات الإصدار:** `scripts/release-smoke.sh` يشغّل نسخة Linux فعلًا، ويشغّل أدوات الوكلاء، ويفحص بنية ملفات Windows.
- **GitHub Actions:** `release.yml` يدوي فقط ويستعمل نفس السكربت. `ci.yml` يدوي فقط.
- **التوثيق:** `docs/RELEASING.md` (بالعربية) وقسم المثبّت في `WINDOWS_SETUP.md`.
