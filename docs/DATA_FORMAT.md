# صيغة البيانات — `.blazanim`

> رقم المخطط الحالي: `schemaVersion: 2` (المرحلة 2). الملفات بالإصدار 1 تُفتح وتُرقّى تلقائيًا، وهذا مُختبَر بملف حقيقي في `tests/fixtures/schema-v1/`.

## 1. الحاوية

ملف `.blazanim` هو أرشيف ZIP (الضغط: Deflate للـJSON، وStore للملفات المضغوطة أصلًا مثل PNG/GLB):

```
project.json          البيانات الوصفية، رقم المخطط، الفهارس
scenes/main.json      المشهد: الشخصيات ووضعياتها الحالية
rigs/<id>.json        الهياكل العظمية، مقابض IK، سلاسل IK، خرائط العظام
poses/<id>.json       مكتبة الوضعيات
clips/<id>.json       مقاطع الأنيميشن
assets/<id>/<file>    ملفات مستوردة مضمّنة داخل المشروع (GLB)، فيبقى المشروع كاملًا حتى لو حُذف الملف الأصلي
metadata/ai/<id>.json   Prompt وSeed وإعدادات التوليد لكل مسودة AI
(سجل العمليات oplog.jsonl يبقى في مجلد الجلسة ولا يُضمَّن إلا باختيار المستخدم)
previews/             صور مصغّرة
```

**لماذا ZIP وليس مجلدًا؟** ملف واحد أسهل للمستخدم في النقل والمشاركة. أثناء العمل يُفك المشروع إلى مجلد جلسة،
والحفظ يعيد بناء الأرشيف.

## 2. الحفظ الذري والاستعادة

1. كتابة الأرشيف إلى `name.blazanim.tmp` في المجلد نفسه (القرص نفسه، شرط للاستبدال الذري).
2. `fsync`، ثم التحقق من الأرشيف بإعادة قراءته ومطابقة checksums: ‏SHA-256 لكل ملف مسجلة في `project.json`. `project.json` نفسه لا يدخل في هذه القائمة، ويُتحقق منه بتحليل JSON وفحص المخطط.
3. الاستبدال الذري:
   - **Windows:** `File.Replace` مع نسخة `.bak`. في **الحفظ الأول** لا يوجد ملف هدف، فنستخدم `File.Move`. عند خطأ مشاركة مؤقت (مضاد فيروسات، مُفهرِس) نعيد المحاولة مع تأخير متزايد.
   - **Linux:** إنشاء `.bak` بـhard link (أو نسخ)، ثم `rename`، ثم `fsync` للمجلد.
4. **ملف القفل** `.lock`: يحتوي على PID واسم الجهاز ووقت البدء، مع قفل نظام التشغيل (`FileShare.None`). القفل القديم بعد انهيار يُكتشف ويُزال بأمان.
5. **الحفظ التلقائي:** كل N دقائق (قابل للضبط، الافتراضي 3) إلى مجلد الاستعادة في بيانات المستخدم المحلية، وليس فوق ملف المستخدم.
   - يستخدم مسار tmp+rename نفسه، مع جيلين متناوبين على الأقل، فلا يُفقد كل شيء إذا انقطع الحفظ في منتصفه.
   - تُؤخذ اللقطة على الخيط الرئيسي، والضغط والكتابة على خيط خلفي.
6. **الاستعادة بعد الانهيار:** عند فتح المشروع تُكتب علامة "جلسة مفتوحة"، وتُحذف عند الإغلاق السليم. عند الإقلاع، إذا وُجدت العلامة مع autosave أحدث من الملف الأصلي، يُعرض على المستخدم الاستعادة أو التجاهل.

## 3. المعرّفات والمسارات

- كل كائن له `id` ثابت (ULID نصي) لا يتغير بإعادة التسمية.
- مسارات الأصول نسبية لموقع ملف المشروع، أو داخلية في `assets/`.

## 4. الترحيل (Migrations)

- `schemaVersion` عدد صحيح. لكل انتقال `n → n+1` دالة ترحيل نقية مع اختبار على ملف عينة محفوظ في `tests/fixtures/schema-v<n>/`.
- يُرفض فتح ملف بمخطط أحدث من البرنامج، مع رسالة واضحة، ولا يُحفظ فوقه.

## 5. مقطع الأنيميشن (Clip)

```json
{
  "id": "01J...",
  "name": "Walk",
  "fps": { "num": 30, "den": 1 },
  "duration": 705600000,
  "skeleton": "01J...",
  "loop": { "enabled": true, "start": 0, "end": 705600000 },
  "rootMotion": { "mode": "extract", "bone": "root", "axes": "xz+yaw" },
  "tracks": [
    {
      "id": "01J...",
      "target": { "kind": "bone", "id": "01J..." },
      "channel": "rotation",
      "keys": [
        { "t": 0, "v": [0, 0, 0, 1], "interp": "cubic",
          "inTan": [0,0,0,0], "outTan": [0,0,0,0] }
      ],
      "locked": false, "group": "Legs"
    }
  ],
  "events": [ { "t": 352800000, "name": "foot_contact_l", "data": {} } ],
  "constraints": [],
  "metadata": { "source": "manual" }
}
```

- `channel`: `translation` (‏3 قيم، متر) أو `rotation` (‏4 قيم، Quaternion xyzw) أو `scale` (‏3 قيم) أو `custom:<name>` (قيمة واحدة).
- كل المراجع بين الكائنات بـ`id` مجرد (ULID) وليس بالاسم، فإعادة تسمية عظمة لا تكسر أي مقطع. الأسماء تُستخدم فقط عند الاستيراد ومطابقة الهياكل.
- `target.kind`: `bone`، أو `control` (أهداف IK وPole، ولها تعريف في الـRig)، أو `object`.
- `interp`: `step` أو `linear` أو `cubic`.
  - `linear` للدوران = Slerp.
  - `cubic` = **Hermite متوافق مع glTF CUBICSPLINE**: `inTan`/`outTan` مشتقات بوحدة "قيمة لكل ثانية"، لكل مكوّن على حدة، والدوران يُطبَّع بعد الحساب. بهذا يكون التصدير إلى glTF دون فقدان.
  - أدوات محرر المنحنيات الإضافية (مثل Bezier الموزون) تبقى داخل المحرر، وعند التصدير تُعاد عيّنتها (resample) بحد خطأ محدد.
- قنوات `custom:<name>` تُصدَّر في JSON sidecar، أو عبر امتداد `KHR_animation_pointer` عندما يدعمه الهدف.
- `t` بوحدة flick (انظر ARCHITECTURE.md §5). الواجهة تعرضه كإطار: `frame = t * fps / 705600000`.
- لا تخزين لمفاتيح مخبوزة (baked) إلا عند الطلب. المقاطع المولّدة بالـAI تُحوَّل إلى مفاتيح مُختزلة قابلة للتحرير، مع حفظ الأصل الخام في `metadata/ai/`.

## 6. الهيكل العظمي (Rig) والوضعيات

**قواعد مهمة (المرحلة 2):**
- العظام مرتبة دائمًا: الأب قبل الابن. يُرفض الملف إذا خالف ذلك.
- الوضعية (`Pose`) تخزّن فقط العظام التي تغيّرت عن وضعية الراحة: `bones` تحويلات محلية (نسبة للأب)، و`controls` حالة المقابض.
- **مقابض IK للأيدي والأقدام** تُخزَّن في فضاء النموذج، فتبقى القدم المثبّتة في مكانها عندما يتحرك الجسم.
- **مقابض اتجاه الركبة والكوع (Pole)** تُخزَّن نسبةً لأول عظمة (الجذر)، فتتحرك مع الشخصية. الأوامر (`pose.set_control` و`pose.get`) تستقبل وتُرجع فضاء النموذج دائمًا.
- **حدود المفاصل:** إما زوايا Euler لكل محور، أو مفصل مفصلي `hinge` (محور + مدى + مخروط انحراف) للركبة والكوع، لأن زوايا Euler تنكسر بعد 90°.
- **الصيغة:** `Transform` في JSON: إذا غاب `scale` يُعتبر (1,1,1)، والدوران يُطبَّع، والحجم صفر مرفوض.


```json
{
  "id": "01J...", "name": "Mannequin",
  "bones": [ { "id": "B_pelvis", "name": "pelvis", "parent": "B_root",
               "rest": { "t": [0,0.95,0], "r": [0,0,0,1], "s": [1,1,1] },
               "mass": 11.2, "limits": null } ],
  "controls": [ { "id": "C_ik_foot_l", "name": "ik_foot_l", "kind": "ikTarget", "rest": { "t": [0.1,0,0] } },
                { "id": "C_pole_knee_l", "name": "pole_knee_l", "kind": "pole", "rest": { "t": [0.1,0.5,0.4] } } ],
  "humanoidMap": [ { "bone": "B_pelvis", "standard": "pelvis" }, { "bone": "B_spine_01", "standard": "spine_01" } ],
  "ik": [ { "name": "leg_l", "chain": ["B_thigh_l","B_calf_l"], "target": "C_ik_foot_l", "pole": "C_pole_knee_l" } ]
}
```

(المعرّفات هنا مختصرة للتوضيح، وهي في الملف الحقيقي ULID.)

`humanoidMap` اتجاهه: **عظمة المستخدم ← اسم العظمة في الهيكل القياسي لـBlazma**. يُستخدم في Retargeting وفي تحويل مخرجات Kimodo.
