## ترتيب العمل في المرحلة 1 (مقترح)

1. هيكل الحل .NET (`Blazma.sln`) + مشاريع الاختبار + CI على Linux وWindows.
2. `Blazma.Core`: الرياضيات (Vec3/Quat/Transform)، الزمن بوحدة flick، نموذج المشروع، التسلسل، الحفظ الذري.
3. `Blazma.Commands`: Registry، Bus، Undo/Redo، oplog.
4. مشروع Godot 4.7 .NET: النافذة، الثيم، اللوحات، الترجمة، ربط الأوامر بالقوائم.
5. Autosave + Crash recovery + اختبار الإغلاق القسري.

## تفاصيل تقنية محددة مسبقًا

- **الترجمة (المرحلة 1):** `TranslationServer` مع ملفات `.po` تُراجَع يدويًا، و`layout_direction` لكل عنصر واجهة، و`TextServerAdvanced` مع تفعيل `internationalization/locale/include_text_server_data` حتى تُصدَّر بيانات ICU (يُتحقق منه عمليًا). خط احتياطي (fallback) للنصوص اللاتينية داخل الجمل العربية. الأرقام في الخط الزمني والحقول الرقمية تبقى أرقامًا لاتينية (0-9).
- **عكس الوضعية Mirror (المرحلة 2):** مستوى العكس هو YZ لأن ‎+Z هو الأمام. اكتشاف الجانبين بأنماط أسماء متعددة (`_l/_r`، `.L/.R`، `Left/Right`) مع إمكانية التصحيح اليدوي، وتصحيح وضعيات الراحة غير المتماثلة.

