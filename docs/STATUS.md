## ما بقي بالترتيب

1. **إصلاح ملاحظات مراجعة المرحلة 9** (مهم):
   - الفحص المكنوس قد يفوّت إصابات حقيقية: سيف طويل يدور بسرعة، Box يدور حول نفسه، أو خصم يتحرك بسرعة. الحل: اختيار عدد الخطوات من الحركة النسبية لكل النقاط الطرفية (+ زوايا الصندوق)، وكنس الـ Hurtbox أيضًا، وتحذير `may_have_missed_contacts` عند بلوغ الحد.
   - تكلفة `combat.hit_test` تتجاوز حدّها (شبكة خطوات مشتركة لكل إطار، وذاكرة مؤقتة تتسع لإطار كامل).
   - `combo.bake`: الضربة الملغاة تستمر حتى نهاية مقطعها وتُنسخ أحداثها بعد الإلغاء (`ComboPlanner.cs:56`).
   - توحيد حدود مدة رد الفعل (0.05–10 مقابل 0.1–5 ث).
   - اتجاه الإصابة يتجاهل دوران الخصم؛ Hurtbox على عظام محذوفة بلا تحذير؛ إعادة التوجيه قد تتجاوز `CombatLimits.MaxTime`؛ ترحيل v4→v5 يرفض أحداثًا قديمة بدل إصلاحها.
2. **إكمال واجهة القتال** واختبارها وصورها.
3. **تقرير المرحلة 9** (`reports/PHASE9.md`).
4. **المرحلة 10:** إكمال التغليف (مثبّت Windows + نسخة محمولة + لينكس)، اختبارات الإصدار، قياس الأداء وتحسين أبطأ الأجزاء، `docs/RELEASING.md`.

## ملاحظات مهمة

- **GitHub Actions:** دقائق الحساب المجانية انتهت لهذا الشهر (تتجدد 1 نوفمبر). الاختبارات التلقائية (`ci.yml`) صارت يدوية فقط. آخر إصدار منشور: `v0.8.0-text-to-motion`. لا تشغّل `release.yml` قبل تجدد الدقائق أو جعل المستودع عامًا، أو ابنِ الإصدار محليًا.
- **Kimodo:** التوليد بالنموذج الحقيقي لم يُجرَّب بعد (الأوزان يجلبها المستخدم بنفسه). `kimodo-runner` مبني ومختبر على Linux وWindows.
- **اللغة:** كل رسائل المستخدم بالعربية.
